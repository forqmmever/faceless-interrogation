## 一、AUfemale.imgpack_v0.9.3 是什么

- **DoL 的图片替换包（imgpack）**，给 ModHub 用的，不是独立素材。
  解压后 9365 个文件（9345 png + 19 gif + 1 svg），压缩包 10516 条。
- **目录与文件名和 DoL 的 `img/` 完全一致**：顶层 19 个衣物槽位目录同名同序
  （back / belly / face / feet / genitals / handheld / hands / head / legs / lower /
  masks / neck / over-head / over-lower / over-upper / props / under-lower / under-upper / upper），
  单件衣物里的文件名也一致（`full.png` / `3.png` / `frayed.png` / `left-idle.png` …）。
- 规模：clothes/upper 3155、clothes/lower 1010、props 691、head 258、handheld 185、
  face 966（含 7 套「改脸」：Twinkle / kiss / nss / 兔子 / 加辣 / 沅芷 / 碱性糖）、
  hair 833、body 267、transformations 163、ui 260。
- **没有 readme / license / 配置文件**，只有一张 `pixil-frame-0.png`（Piskel 编辑器的导出残留）。
- 缺 DoL 的 `img/dolls`、`img/sex`、`img/misc/icon`（★ 物品图标没有，得沿用 DoL 的）。

## 二、几何：这是最关键的差异

| | DoL 原版 | AUfemale |
|---|---|---|
| 画布 | **256×128**（2 帧 ×128×128） | **512×256**（4 帧 ×128×128） |
| 正面全身帧 | 第 0 帧，人物 x 50–70、y 42–93（**20×51**） | 第 0 帧，人物 x 88–121、y 47–187（**33×140**） |
| 第 1 帧 | 同上（重复） | **胸像特写**（x 139–249，y 47–192） |
| 第 2/3 帧 | 无 | 与第 0/1 帧几乎逐像素相同（只有 151 px 差异） |

→ AU 不是 DoL 的等比放大：人物**重画过**，比例变高（有完整双腿），
  头部 33 px 宽（DoL 22 px，约 1.5×），全身 140 px 高（DoL 51 px，约 2.7×）。

**★ 坑：人物的 y 跨过了 128 的格子线**（47→187）。所以 `dol_prepare.py` 的
`frame0()`「扫 128 网格取第一个非空帧」对 AU 是错的 —— 会只拿到大腿以上，
`compute_crop()` 又会被 `FRAME=128` 夹住，腿直接截掉（实测：烘出来 53×122，膝盖以下没了）。

## 三、包内几何是「混的」

- `body/`、`clothes/`、`face/` 基本都是 512×256（新几何）。
- `hair/sides` 288 个 512×256 + 85 个 256×128；`hair/fringe` 223 新 + 133 旧；
  `hair/back` 27 新 + 13 旧。按款式算：**98 个新几何 / 47 个旧几何**。
- AU 另外多出一个 `hair/hair/`（512×256，只有 `straight` 6 个 + `sides/thick twintails` 6 个）。
- 上色不一致：`hair/sides/*` 大多是灰黑色，但 `hair/fringe/centred` 是**红的**（DoL 原色残留）。

## 五、结论

**能替换，但不是换目录那么简单。** 三件事必须做：

1. `dol_prepare.py` 加「每包一套几何配置」：帧宽高、取哪一帧、人物在帧里的位置。
   AU = 4 列 ×1 行、每帧 128×256、取第 0 列；`compute_crop` 不能再夹 128。
2. 图层要先**归一化几何**：512×256 直接用，256×128 的按 2× 放大再对位
   （对不上的旧几何层要么换新几何的同名文件，要么剔除）。
3. `dol_map.py` 里 13 条映射要重挑；`hair_short` 的 `sides/classic` 在 AU 里没有，
   得改成 `sides/default` 或 `hair/hair/straight`。

**顺带的连带影响**：取景框从 41×92（比例 0.446）变成约 76×200（比例 0.38）——
小人更高更窄，`Wardrobe` 的预览区（123×276）、`PhoneDesk` 相册的 `PHOTO_FOCUS` 都要重算；
卡片图标继续用 DoL 的 30×30（AU 没提供）。

**许可**：包里没有任何 license/readme，是中文圈的 DoL 同人拼包（face 下 7 套「改脸」
按作者命名）。DoL 本体是免费同人游戏、美术是社区协作的，拿它的图做二创在本项目
这个语境下与之前「引入 DoL 美术」是同一性质，但**不建议对外分发时打包这批图**。
