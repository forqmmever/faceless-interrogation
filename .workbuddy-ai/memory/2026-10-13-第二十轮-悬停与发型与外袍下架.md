# 第二十轮（1/3）：悬停文案 / AU 发型重做 / 外袍下架

用户本轮把需求拆成三轮。本轮只做第 1 轮三件事。

## ① 悬停去掉「与他记忆里的一致 / 不同」
`scripts/Wardrobe.gd::_tip_for()` 删掉那两行提示。
理由：原貌开局即全部可见，卡片上再写「一致 / 不同」等于把答案印出来，
搭配的乐趣（自己去情报台比对）全没了。
现在悬停只留三项精确读数：暴露值 / 反差值 / 需接受度；
未解锁的装扮只说「该部位原貌未知 —— 你无法判断这一件」。

## ② AU 的 4 款发型全部换成 AU 自己重画的新几何款
关键坑：AU 图包里**同时留着 DoL 的旧款**，同名（`middlepart` / `twin braids`…）
但仍是 256×128 旧几何 + DoL 红发色（sat 0.50~0.90）。
所以 AU 发型表**不能写成候选列表**（会先撞上旧款），必须点名新几何款。
`sides/wavy braid` 是「新几何但仍红色」的漏网款（sat 0.66），也不能用。

另一关键：**AU 头发是纯灰度蒙版**（实测饱和度 0.00，亮度 38..207），运行时染色。
→ AU 头发必须走 `tint()`（乘颜色）+ `gain` 亮度增益，
  而不是 `hue_shift()` —— 在饱和度 0 的灰度图上色相旋转毫无意义
  （第 4 款原来因为 `hue: None` 干脆没换色，结果渲染成灰白）。

新增 `tools/dol_map.py`：
```python
HAIR_TINT_AU = (0.42, 0.30, 0.21)   # 深棕
HAIR_GAIN_AU = 1.25
HAIR_STYLES_AU = { "hair_short": neat/default, "hair_braid": braid right/curtain,
                   "hair_long": all down/parted + back all down, "hair_up": messy bun/parted }
PACK_HAIR = { 'dol': HAIR_STYLES, 'au': HAIR_STYLES_AU }
```
`tools/dol_prepare.py` 头发循环按图包选表 + 支持 tint。
产物：`assets/dol_au/base/hair_*.png` 重烘（深棕、sat≈0.50、avgRGB≈(58,42,30)）。
`assets/dol/` 139 张 png **逐像素完全一致**（零回归）。
