# 第 69 轮 · 自行编辑的背景不自动加说话人名牌

日期：2026-10-17

## 用户口径

> 第一次：「自行编辑的题目不要在前面自动加什么黄毛，苦主，你」
> 补充：「对应前面你删去我给的文档中人物名字的理由」
> 再补充：「自行编辑的题目不要在前面自动加说话人名牌」

即：**只对 `questions_source = "manual"` 的背景**去掉自动前缀；
`auto` 背景保持原来的「说话人：」「你：」观感。

## 现在的行为

`Interrogation._load_question()` 先取：

```gdscript
var manual := RunData.questions_are_manual()
```

然后交给 `_dialogue_text(manual, speaker, echo_text, custom, qtext)`：

| 背景 | 题面前 | 上一题默认回应 |
|---|---|---|
| **manual** | **不加**「苦主 / 黄毛」 | **不加**「你：」，原样接上 |
| **auto** | 保留「说话人：」 | 保留「你：<上一题选的>」 |

- `manual` + 自带 `echo`：原样（这条本来就不加「你：」）。
- `manual` + 留空 `echo`：原样（不再补「你：」）。
- 说话人如果要在画面上出现，直接写进题目正文 / 选项回应。

## 为什么保留 speaker_* 三条文案

`speaker_interrogator` / `speaker_companion` / `speaker_you` **没有删** ——
auto 背景还在用。`interrogator`（审讯官称呼）也保留，三处旧功能还在读它。
这跟第五十六轮「manual 模式收起字段」是同一个原则：**字段是内容，不是显示逻辑**，
所以数据不删，只按模式决定拼不拼。
