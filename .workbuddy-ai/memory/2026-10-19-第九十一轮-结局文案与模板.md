## 用户口径（原文）

> 「结局文案中不加 %s 也不会报错，将玩玩的关系的结局文案，作为未填写时，自动显示的模板」

**推翻了第八十一轮**的「结局文案中所有的部分不写默认不使用」。

## 根因（探针实测）

`Interrogation._etf()` / `Main._etf()` 原来是：

```gdscript
var t := _et(key)
if t == "": return ""
return t % args
```

GDScript 4.3 裸 `%` 在「参数个数 ≠ 占位符个数」时的真实行为（`tools/probe_pct.tscn` 实测，用完已删）：

| 写法 | 控制台 | 返回值 |
|---|---|---|
| `"没有占位符" % ["甲","乙","丙"]` | `ERROR: not all arguments converted` | **`""`** |
| `"只有 %s 一句" % ["甲","乙","丙"]` | 同上 | `""` |
| `"%s 和 %s" % ["甲"]` | `ERROR: not enough arguments` | `""` |
| `"" % ["甲"]` | `not all arguments converted` | `""` |

→ 用户把「玩玩的关系」的 `recognized_line` 改成 `【伪装失败 · 一眼认出】`（没有 `%s`）之后，
「一眼认出」「本局失败」那几屏**整段空白**。端到端日志里一次跑刷 **21 条 ERROR**。

## 关键设计：模板必须读数据，不能抄常量

```gdscript
const ENDING_TEMPLATE_BG_ID := "scene_1"     # 「玩玩的关系」

func ending_template() -> Dictionary:
	_ensure_story()
	for b in _backgrounds:
		if str(b.get("id", "")) == ENDING_TEMPLATE_BG_ID:
			var e = b.get("endings", null)
			if typeof(e) == TYPE_DICTIONARY: return e
	return DEFAULT_ENDINGS

func endings_of(bg: Dictionary) -> Dictionary:
	var out: Dictionary = ending_template().duplicate()
	if str(bg.get("id","")) == ENDING_TEMPLATE_BG_ID: return out
	var e = bg.get("endings", null)
	if typeof(e) != TYPE_DICTIONARY: return out
	for k in e:
		if typeof(e[k]) == TYPE_STRING and str(e[k]).strip_edges() != "":
			out[k] = e[k]
	return out
```

★ 抄一份进 `DEFAULT_ENDINGS` 就是两个真相源 —— 用户改「玩玩的关系」时另一份不动。
★ 「未填写」= 缺键 / 空串 / 全空白，三种都回落。
★ 模板里没有的键 → 空串（界面不显示）—— 测试用 `__no_such_ending__` 钉住这条。
★★ **副作用：现在做不到「这一句不显示」了** —— 模板里有字就一定有字。
要清空某一屏，得把模板那套对应条目也清掉。这是用户这条口径的必然结果，已在 README 写明。

## 安全格式化

```gdscript
func count_placeholders(t: String) -> int:
	var n := 0; var i := 0; var L := t.length()
	while i < L:
		if t[i] == "%":
			if i + 1 < L and t[i + 1] == "%": i += 2; continue
			n += 1
		i += 1
	return n

func fmt_args(t: String, args: Array) -> String:
	if t == "": return ""
	var need := count_placeholders(t)
	if need <= 0: return t.replace("%%", "%")
	var use: Array = []
	for i in need:
		use.append(args[i] if i < args.size() else "")
	return str(t % use)
```

★ 只在**结局文案**这条路用。`ui` 的 `_tf/_ut` 仍是裸 `%`（占位符个数由编辑器 `f.ph` 守着）——
用户只提了结局文案，没顺手扩口径。
