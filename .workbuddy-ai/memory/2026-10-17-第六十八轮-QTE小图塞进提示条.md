# 第 68 轮 · 把 QTE 下腹部小图塞进提示条（修「界面不正常」）

日期：2026-10-17

## 用户口径

> 「之前表情 qte 加入了一张图片导致出现该 qte 时界面变得不正常，请调整」

## 原因

第六十三轮把换装下腹部截图做成了**屏幕右侧 232×232 的悬浮面板**：

- 大图会盖住题面 / 选项的右半边，看起来像一块突然多出来的窗口；
- `SubViewport` 用 `UPDATE_ALWAYS`，QTE 期间每帧重渲染一张大图；
- 面板是独立于 QTE 条的一层，和 QTE 条的视觉不是一套。

## 调整

1. **不再悬浮**：删掉右侧 PanelContainer / MarginContainer / 背景边框，
   把截图 + 屁股轮廓 + 五指手缩成 **64×64**，塞进**表情 QTE 条右侧**。
2. **QTE 条布局**：`_make_bar_overlay()` 的 `m` 下面改成 HBox：
   `VBox（提示文字 + 进度条）` + `64×64 thumb`；
   只有表情 QTE 传 `with_thumb = true`，递话条保持原样。
3. **右边距**：QTE 条右侧 170 → 24，否则内容会把缩略图挤到面板外面
   （第一次改完截图里缩略图确实跑到条外，成了另一个黑方块）。
4. **性能**：`SubViewport` 从 `UPDATE_ALWAYS` 改成 `UPDATE_ONCE`；
   换装 / 每次 QTE 出现时各刷新一次，不再每帧渲染。
5. 缩略图仍不挡鼠标，仍随 QTE 出现 / 消失。

## 结果

`19_expression_qte.png` 里现在是：屏幕最下方一条完整的 QTE 条（左 170 / 右 24），
文字和进度条在左，64×64 的下腹部缩略图在最右，不再盖住题面和选项。
