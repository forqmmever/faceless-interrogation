### 踩过的坑（本轮新增，务必记住）

1. **★ 隐藏中的 Control 不参与布局，`size` 会一直停在 (0,0)。**
   `HelpOverlay` 在 `_ready()` 里 `visible=false`，之后 `open()` 显示出来时尺寸仍是 0 ——
   结果整个标注层画在一个 0×0 矩形里，截图与屏幕**逐字节等于底图**。
   修法：`_area()` 取不到自己的 size 就退回 `get_viewport_rect().size`；
   `open()` 里 `_sync_layout()` + `layout_deferred.call_deferred()`；`resized` 也接上。
2. **python heredoc 里写 `\n` 会变成真换行**，把 GDScript 字符串搞成跨行 → `venue` 字段解析崩掉。
   写多行文本进 `.gd` 要用 Edit 工具，或者写 `\\n`。
3. 用 python 替换「整行」时，若替换串里没带上原键名，会把那一行**整个删掉**（`venue` 就这样丢了）。
4. `DumpStory` 导出的是**当前生效的数据** —— 想让它导出 `DEFAULT_*` 的新内容，
   必须先把 `data/story.json` **改名移走**（复制不行）。
5. `_load_question` 里 `_cancel_qte()` 会把 `qte_done = true`，之后排新 QTE 必须 **重新置回 `qte_done = not qte_needed`**，
   否则延迟永远不倒数。
6. 延迟走完那一帧**不能把超出的时间算进 QTE 窗口**，否则一次大步进（测试 / 卡帧）会把 QTE 一帧走完。
7. `_process` 里 `interference_timer` 在 QTE 期间暂停排干扰（空格一键两用会互相打架）。
