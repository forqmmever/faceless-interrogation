# 第九十轮 · 备忘录改成每轮自写的一段手记

日期：2026-10-19

## 用户口径（原文）

> 「备忘录改成每条都是有正文，第一条可以额外设置绑定盲题的部分也可以不选，
> 也自动填写到正文，最后效果是点进备忘录的每一套会是一段文字」

之前三轮澄清得到的口径：
- 每条 = 有正文；**每轮一份完整列表**（不累积）
- 第一条可勾「绑定盲题」→ 自动接一行「该怎么答：<性情 hint>」
- 正文支持占位符，**不写也行**
- 最终渲染成**一段连续文字**（不是一条一卡）
- 原来自动生成的两条（性情 / 这一局的人）**整块下线**

## 关键实现细节

### 渲染
```gdscript
var paras: Array = DossierData.level_memo_bodies()
if DossierData.level_memo_hint():
    paras.append(_tf("memo.howto_line", [DossierData.interrogator_hint()], "该怎么答：%s"))
if paras.is_empty():
    return          # 一段都没有 → 连卡片都不建
```
- `screen_box` 在 `ScrollContainer` 里，写多少段都能滚。
- 占位符替换**带右花括号**，所以 `{审问者}` 不会吃掉 `{审问者性别}`。

### 数据注入的坑（重要）
`RunData.levels()` **每次都重新 duplicate**，`RunData.current_level()` 返回的是临时副本 ——
测试里想注入 `memo` 必须改 `OutfitData.level_at(i)` 返回的那份（它是 `LEVELS` 里的同一对象）。
第一版写成 `RunData.current_level()["memo"] = ...`，静默无效。

### 逐行插入 JSON
`json.loads → dumps` 整体重写会把 story.json 退回旧版（第 78 轮踩过）。
本轮用 `json.JSONDecoder().raw_decode` 逐个对象定位，再在「对象最后一个 `}` 所在行的行首」插入，
写完断言：背景数 / 每套轮数 / 题数 / 强制规则数 / 短信数 / 顶层键 全部不变。
★ 第一次写的插入文本多带了 `",\n"`，产生 4 处孤立逗号行（`\n,\n`）—— 已用一次 replace 修掉并断言长度差 = 4。

### 测试的自洽
- 备忘录断言**不依赖数据配没配**：没写就临时注入，跑完还原（`had_*` 三态判断）。
- 盲区反馈断言**直接调 `_answer_blind()`**，不点选项 —— 否则被「当前数据里那道盲区题长什么样」绑住
  （数据一改整段红，本轮实测就是这么红的）。
- 对照断言：清空 memo → 先确认「此刻确实是空的」→ 再答一次 → 反馈仍必须给出脾性与忌讳。
