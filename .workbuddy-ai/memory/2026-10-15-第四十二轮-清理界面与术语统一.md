# 第四十二轮：清掉改之后没用的界面 + 术语统一（关 → 轮）

日期：2026-10-15

## 用户口径

> 「把改之后没用的界面删一下」

并先明确了术语（重要，之后一律照此）：

> 「我以后说的一局游戏是指，包括背景有多轮换装和问答的一局游戏，也是点开始游戏的后选择的不同的游戏内容
> 一轮是指一局游戏下一次换装加问答环节」

## 一、删掉的废弃占位节

背景页的「⑤ 盘问题目 → 已并入「🗣 题库」页」——
第二十九轮起题目已统一到题库页，这节只剩一个**只读**字段 `questions_schema`。

★ 删它**不影响数据**（字段仍在 story.json 里，只是编辑器不渲染）。
★ 冒烟测试里那条「这节存在」的断言改成了**反向断言**（防止以后又被加回来）。

## 二、重排背景页编号 + 顺序

第 41 轮插「本局覆写」时把编号弄乱了：③⑥⑥⑥④⑤⑧⑨⑩。
现在：①~⑥ 是 A 本人的设定、⑦ 是本局流程覆写（5 节同号成一组）。

★ **不只是改标题** —— 把那几节在**数组里**挪到末尾，让**显示顺序与编号一致**。
（以前 ⑦ 显示在 ③ 上面。）

顺带修：`interference_lines` 的 hint 还写着「他的正式提问在上面第 ⑥ 节」（题目早搬走了）。

## 三、★ 真 bug：通关文案写死「4 / 4 关」

第 41 轮起轮数可按背景配（某套背景可只打 3 轮），而
`endings.overlay_win_body` 里是写死的「成绩 4 / 4 关全部通过」→ 会显示错误。

改成 `%d / %d 轮全部通过`。

★ **连带**：占位符数量 **5 → 7**，必须同步改 `Main._win_body()` 的参数表
（否则运行时「not all arguments converted」）。
而且这文案有**两份**：story.json 里那份（游戏实际读）
+ `ScenarioData.DEFAULT_ENDINGS`（json 缺失时兜底）—— 两处都要改。

`overlay_fail_body` 的「已通过 %d / %d 关」同一个毛病，一并修。

## 四、术语统一：关 → 轮（范围要精确！）

用**模式表**而不是全局替换：

| 改（轮次语义） | 不改（无关用法，用 SKIP 词表挡） |
|---|---|
| 本关→本轮 / 这一关→这一轮 / 每关→每轮 | 关口 / 关隘（地名） |
| 上一关→上一轮 / 下一关→下一轮 | 通关文书 / 进关 / 过关（剧情动词） |
| 第 N 关→第 N 轮 / 关卡→轮次 / 几关→几轮 | 关心 / 关键 / 相关 / 关闭 / 关注 |

★ 改完**必须复查 diff** —— 实测只有一处
`第四关 · 关隘地牢前厅` 因含「关隘」被整行跳过，手工改前半、保留地名。

★ 涉及 **13 个 GDScript + story.json + 3 个测试文件**。
★ 测试里的**期望值**必须同步 —— 实测挂了 4 条，全是 `contains("第 2 / 4 关")` 这种。
  **「文案统一」不能只改实现不改测试。**

★ 脚本里 `line.split('#')[0]` 会把 `[color=#8a919c]` 里的 `#` 当注释起点 ——
  BBCode 颜色代码会打断「代码 / 注释」的切分。虽然结果凑巧是对的，
  但判断依据乱了。**处理含 `#` 的颜色标记时别用 `#` 切注释。**

## 五、给五个「全局默认」页加提示

「🪜 关卡与轮数 / 👗 强制穿着 / ⏱ QTE 计划 / 🩹 身体缺陷 / 🎭 原貌」现在是
**四套背景共用的默认值**，可被「⑦ 本局覆写」整份取代。

不说明的话，用户改了没生效会当成 bug。每页加了：
「★ 这是『默认值』—— 可以被单局覆写 / 背景里写了内容非空 → 整份取代」。

★ 特别地，关卡页的 `name` / `derived_profile` **只在这一套背景没写轮次名时生效** ——
游戏里显示的是背景那份，因为**选轮面板要在开局前显示名字**，那时还没抽背景。

## 七、新建的规矩

1. **改「文案」要同时找三处**：GDScript 默认值 / story.json / 测试里引用了它的期望值。
   漏掉任何一处都会挂或显示旧文案。
2. **改占位符数量 = 改接口**：文案里多一个 `%d`，所有调用点的参数表都要补。
3. **清理界面时，把「存在性断言」改成「反向断言」** —— 否则以后有人加回来测试也不会响。
4. **「删掉一个数组元素」和「改标题」是两件事** —— 编号理顺了但元素位置没动，
   显示顺序还是会乱。改完要**回读渲染顺序**确认。
