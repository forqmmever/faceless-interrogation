# 第二十一轮（2/3）：失败回本轮开始 + 四关选关入口

用户把需求拆三轮，本轮做第 2 轮两件事。
第 1 轮（悬停文案 / AU 发型 / 外袍下架）见 `2026-10-13-第二十轮-悬停与发型与外袍下架.md`。

## ① 失败 → 回到本轮开始

旧规则：任何一关失败 → 整局作废，重抽背景与原貌（`RunData.fail_run()`）。
新规则：**只作废这一轮** —— 回到本关的准备室重来。

核心是「本轮快照 / 回滚」：

- `GameData.snapshot_level_state()` / `restore_level_snapshot()` / `has_level_snapshot()`
  存 8 个字段：`stated_facts` / `contradictions` / `improvised` / `plants` /
  `companion_asked` / `answer_log` / `interrogator_sms` / `suspicion_carry`。
- 拍快照的时机（必须有快照才回滚得动）：
  - `Main._start_new_run()` 结尾
  - `Main._start_level()`（通过一关进下一关时）
  - `Main._continue_run()`（续玩也算本轮开始）
- `RunData.retry_level()`：回滚 + 重确认强制装备（同关同种子 → 同结果）+ 发 `level_retried` 信号。
- `Main._retry_level()`：`RunData.retry_level()` → `wardrobe.start_level()` →
  `GameData.begin_level_suspicion()` → 写档 → 弹开场说明。

**回滚什么 / 留什么**（关键设计）：
- 回滚：本轮立下的说法、矛盾计数、问答记录、掏手机事故短信、怀疑度底子。
- 留着：**前面几关立下的口径**（跨关复问因此仍成立）、短信进度、相册、外貌情报、
  身份归类、接受度、装备池。→ 「他记忆里的那张脸没变，你已经查到的也还在，
  要改的只是这一轮的打扮。」

其它连带改动：
- `Main._on_interrogation_finished()` 失败分支：`note_run_finished(_, false)` → `note_level_failed()`；
  `RunSave.clear()` **删掉**（这一局还在进行中）；`_pending_action = "retry_level"`。
- `ProfileData`：新增 `level_failures`（累计「本轮重来」次数）+ `note_level_failed()`。
  **失败不再计入 `runs_played`** —— 否则同一次失败会被重复计数。
  `summary()` 改成「累计接受度 / 通关 N 局 / 本轮重来 N 次 / 单局最好 N/4 关」。
- `_pending_action` 取值扩成 `"next_level" | "retry_level" | "new_run"`。
- 文案（`ScenarioData.DEFAULT_ENDINGS` + 四套背景的 `endings`）：
  `overlay_fail_title`「💀 潜伏失败 · 本轮重来」、`overlay_fail_body`、
  `result_fail_btn` / `result_recognized_btn`「重来本轮 ↺」、
  `result_fail_hint` / `result_recognized_hint` / `recognized_note`。

## ② 「开始游戏」→ 四关选关入口

- `OutfitData.OPEN_LEVELS := [0]` + `level_unlocked(li)` + `open_level_count()`。
  **锁定 ≠ 删除**：`LEVELS` 四条曲线、关卡名、题目编排一件没动，只是按钮置灰。
  以后开放第 N 关 = 把下标加进这张表，别处一行不改。
- `Main` 新增选关面板：`_build_level_select()` / `_show_level_select()` /
  `_hide_level_select()` / `_is_level_select_open()` / `_on_level_selected(li)` /
  `_on_level_select_back()`，`level_select_rows` = [{btn, note, li}]。
  四行 = 关卡名 · 推导形象（取自 `OutfitData.LEVELS`）+ 右侧「可以进入 / 尚未开放」。
- `Main._on_title_start()` 改成只 `_show_level_select()`，不再直接开局。
- `RunData.start_new_run(seed_in, start_level = 0)`：
  `level_index = clampi(start_level, 0, level_count()-1)`、`cleared_levels = level_index`。
  **前面几关的接受度加成不补**（这也是后三关暂时锁着的另一个理由）。
- 新界面文案 5 条（`ui.title.select_*`）：`select_title` / `select_sub` /
  `select_open_note` / `select_locked_note` / `select_back`。
  同步改了 `tools/story_editor.html` 的 `uiSections()` ② 段标题与字段，
  所以 `editor_smoke.js` 里 `uiLeafCount` 74 → **79**（两处断言）。
- 注意 `HBoxContainer.ALIGNMENT_*` 在 Godot 4 里是 `BoxContainer.ALIGNMENT_*`；
  类型推断坑：`var x := gd.suspicion_level` 会报
  "Cannot infer the type"，要显式 `var x: float = ...`。

## 测试

`tests/WardrobeTest.gd` **338 → 361**：
- `_test_level_curve()` 里「整局重开」段改成「本轮重来」段（13 条断言）。
- 新增 `_test_open_levels()`：只开第一关、其余锁定、**锁定不等于删除**、
  从第 N 关开局、同种子强制装备可复现、越界起始关夹回。
- `_test_profile()`：失败不再计入 `runs_played`，改成断言 `level_failures`。

`tests/TestRunner.gd` **810 → 850**：
- `_test_boot()`：点「开始游戏」→ 选关面板 4 行、只第 1 行可点、
  点锁定关无效、返回可回开始界面。
- `_test_recognition_on_sight()`：识破后改成「重来本轮」，断言局号 / 关卡 / 背景 / 原貌全不变。
- `_test_leak_and_fail_restart()`：同上的失败段改写。
- 新增 `_test_retry_level_semantics()`：跨关口径保留 + 本轮口径回滚 +
  怀疑度回落到进关值 + 情报进度保留 + 局内存档不清。
  坑：问答记录只在 `kind == "card" | "blind"` 时才写 → 验证回滚要挑**盲区题**。
- 新增 `_arr_eq()` 辅助。

结果显示 **361 / 850 / 113 / 97 = 1421 全绿**。
