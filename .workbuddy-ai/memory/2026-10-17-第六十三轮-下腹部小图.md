# 第 63 轮 · 表情 QTE 旁的「换装 · 下腹部」小图

日期：2026-10-17

## 用户口径

> 「能否在第二阶段时，将换装的结果，下腹部截图，然后画出屁股的形状，
> 最后在上面画一个张开五指的手，并且随表情qte一起出现和消失」

## 实现

表情 QTE 弹出时，屏幕**右侧中部**出现一块 **232×232** 的小面板：

1. 底图：当前这一身打扮按 `BODY_CROP = Rect2(18, 90, 32, 32)`（DolDoll 取景框 68×203
   里的下腹部区域）重新铺进一个 `SubViewport`，再用 `TextureRect` 显示。
   **不是抓整屏** —— 换装结果改了图就跟着改，也不会把 UI 拍进去。
2. 上面叠 `BodyPreview.gd` 画的：两瓣屁股轮廓（左右外弧 + 底部中点 + 顶部凹口 + 中间沟）
   和一只张开五指的手（手掌圆 + 拇指/食指/中指/无名指/小指，深色描边 + 肉色填充）。
3. 显示 / 隐藏跟着表情 QTE 的**同一个生命周期**：
   `_begin_qte()` → show；`_finish_qte_for_question()` / `_cancel_qte()` → hide。
   答完题、超时、被识破、换题都会收掉。

## 关键细节

- **截图来源**：`Main._on_wardrobe_confirmed()` 在 `wardrobe.hide()` **之前**把
  `wardrobe.model.equipped` 传进来。测试 / 截图脚本直接调 `_start_expression_qte()`
  时没有这一步 —— `_ensure_body_preview()` 用 `RunData.true_appearance()` 兜底。
- **面板不吃鼠标**：`body_layer` / panel / TextureRect / BodyPreview 全部
  `MOUSE_FILTER_IGNORE`，QTE 期间照样能点选项。
- **不挡底部提示条**：面板在右侧中部（y 约 224~496），蓝色 QTE 条在屏幕最下方。
- **`BODY_CROP` 是取景框坐标**，不是屏幕坐标。改小人的取景框（`DolDoll.frame_size()`）
  或换图包时要重新对一下这块。
- **凹多边形不能直接 `draw_colored_polygon`**：第一版用「心形参数曲线」一笔画完，
  截图直接报 `Invalid polygon data, triangulation failed`，那一张图被跳过、留下旧文件。
  现在填充拆成**两个椭圆 + 底部一块**（都是凸多边形），轮廓另用 `draw_polyline` 画。
- 画完记得看 `shots` 日志里的 `triangulation` / `frame_post_draw 超时`：
  绘制报错不会让测试失败，只会让截图静默跳过。
