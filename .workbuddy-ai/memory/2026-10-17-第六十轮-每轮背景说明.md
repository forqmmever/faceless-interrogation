# 第 60 轮 · 第二轮也有背景说明浮窗，而且与第一轮不同

日期：2026-10-17

> ★ **第七十二轮更正**：下面「编辑器」那一行写的「`levelsFields()` 新增一栏，
> 在「⑦ 本局覆写」里逐轮改」是**错的** —— `levelsFields()` 只给「🪜 关卡与轮数」页用，
> 背景页的「⑦ 本局覆写 · 几轮」是**另写的一份字段表**，那份里没加 `intro`，
> 所以用户一直改不到。第七十二轮已补上，详见 `2026-10-18-第七十二轮-每轮说明可编辑.md`。

## 用户口径

> 「每局游戏的第二轮也会有背景说明的浮窗，并且与第一轮不一致」

## 结论

浮窗本来就会在**每一轮进准备室时**弹（`Main._start_level()` 里调 `_ensure_intro_shown()`），
但正文一直取整套背景的 `intro`，两轮长得一模一样。本轮把正文改成**按轮取**：

- 数据：`backgrounds[].levels[i].intro`（每轮一条）。
- 运行时：`DossierData.intro_text()` 先读 `RunData.current_level().get("intro", "")`，
  非空就用它；空才回落 `ScenarioData.intro_of(RunData.background())`（原来的总 `intro`）。
- 编辑器：`levelsFields()` 新增「这一轮的背景说明（可空）」一栏，在
  「⑦ 本局覆写 · 几轮 + 每轮的名字 / 说明 / 数值」里逐轮改。

## 数据（5 套背景都补了）

| 背景 | 第一轮 | 第二轮 |
|---|---|---|
| 边境哨卡 | 原 `intro`（复制进 `levels[0].intro`） | 老兵换了一本更旧的册子，从头再问；老崔靠在门框上 |
| 城镇驿站 | 原 `intro` | 驿丞说还有几处对不上，灯推过来再问一遍；背琴的年轻人坐到楼梯口 |
| 公爵府邸 | 原 `intro` | 执事取出更厚的册子，再写一遍、再说一遍；程九站在门边 |
| 港口海关 | 原 `intro` | 验货官摸出一本旧港簿，潮水涨了，再问一遍；阿鲛把缆绳绕了两圈 |
| 情景一（草稿） | 桌游店偶遇 + 任务 + 校服要求 | 生日宴前情 + 变装 |

四套出厂背景的 `levels` 原本是 `[]`（回落全局），现在变成 2 条：
第一条复制总 `intro`，第二条是新的续场说明。这样两轮都能在编辑器里逐条改，
`intro` 保留为「哪一轮没写时」的兜底。

## 代码改动

| 位置 | 改动 |
|---|---|
| `DossierData.intro_text()` | 按 `RunData.current_level()["intro"]` 取，空则回落 `ScenarioData.intro_of()` |
| `tools/story_editor.html` `levelsFields()` | 新增 `{k:"intro", t:"area", rows:5}` |
| `tools/story_editor.html` 基础信息 `intro` | 标签 / hint 改成「总说明」，说明每轮可以覆盖 |
| `tools/story_editor.html` 标题 | 「⑦ 本局覆写 · 几轮 + 每轮的名字 / 说明 / 数值」 |
| `data/story.json` | 5 套背景的 `levels[]` 各补 2 条 `intro` |

**`OutfitData` / `RunData` 一行没改**：`_ensure_levels()` 本来就会把背景 `levels[i]`
里除 name / derived_profile 外的键原样并进 `LEVELS`，`RunData.levels()` 再 `duplicate()`
—— 所以 `intro` 自动出现在 `current_level()` 里。这是这轮最省事的地方，也是最容易
看漏的地方：**不要再去 `RunData.levels()` 里手动抄一遍**。

## 踩坑 / 注意

1. **`levels` 数组长度 = 本局打几轮**。给四套背景补 2 条，长度仍然是 2，轮数不变；
   只写 1 条会把这一局压成 1 轮。
2. **第一轮的说明是复制进 `levels[0].intro` 的**，不是继续读 `intro` ——
   这样两轮都能在编辑器里逐条改。`intro` 只是「某一轮没写」时的兜底。
3. **`intro` 三处提示要一致**：编辑器基础信息那一栏写「总说明」、levels 那一栏写
   「留空 = 用总 intro」，否则用户会以为改了总 intro 第二轮也会跟着变。
4. **`DossierData.intro_text()` 的回落顺序不能反**：先本轮、后总说明。
   反过来会让第二轮的浮窗永远回到第一轮的文案。
5. 测试里切第 2 轮时**直接改 `RunData.level_index` / `cleared_levels`，不要用
   `advance_level()`** —— 后者会 `ProfileData.add_gain()`，跨局累积会污染后面的用例。
   用完记得把两个值还原再 `_start_level()` 回第 1 轮。
6. 按用户要求，本轮**没有更新 `交接.md` 与 `CHANGELOG.md`**。
