## 一、DoL 的换装系统长什么样（实测，非印象）

参考物是单文件 Twine（SugarCube）游戏，`E:/DOWNLOAD/Degrees of Lewdity/Degrees of Lewdity 0.5.12.13.html`，
52MB，16087 个 `tw-passagedata`（passage 可以直接正则抽出来读）。

- **衣物卡片** `.clothing-item`：`inline-flex`、宽 49%、1px 实线边框、悬停换 `var(--850)` 底色；
  卡片里是「缩略图 + 名称 + 三行数值 + 一枚斜着的价签」。缩略图是 `img/misc/icon/clothes/*.png`
  的 **30×30** 图标，CSS 里 `transform: scale(2,2)` + `image-rendering: pixelated`。
- **数值 = 7 颗小圆点** `.stats-ball`（5×5、圆形、1px 描边）：点亮几颗＝量级，颜色＝档位。
  三行是 `I.`（耐久）/ `R.`（暴露）/ `W.`（保暖），档位由 `getIntegrityInfo` / `getRevealInfo` 硬切：
  暴露 R. 低→高 = 绿 青 浅蓝 蓝 紫 粉 红；耐久 I. 反过来。
- **连续量**另有 `.warmth-scale-div`（10px 圆角、`linear-gradient(dodgerblue, lemonchiffon, red)`）
  + `.warmth-indicator` 箭头指针。
- **小人**是 128×128 的分层 canvas：身体/脸是**彩色**贴图（`img/body/base-<体型>.png`，
  人物本体只占约 20×73 px），服装是**灰度遮罩**（7891 张 `clothes/<槽位>/<款式>/full.png`），
  运行时由 `Renderer.composeOverCutout` 染色 —— **结果 = 颜色 × 蒙版灰度**（先填色成遮罩形，再 multiply 回原图）。
  图层 z 序在 `ZIndices` 里（basehead 5 / base 20 / 手臂 30 / 眼睛 30~35 / 嘴 40 / 头发 60 /
  刘海 132 / 耳 132.5 / 眉 138 / facewear 145 / head 149 / neck 103 / 上身 95 / 下身 90 …）。
  显示端 `img, canvas { image-rendering: pixelated }`。

## 二、本作落地的产物

- `scripts/DolStyle.gd`：色板（抄 DoL 的 `--green #38b20a` 等）、三条 7 档色阶、
  `Pips`（七点控件）、`Scale`（渐变刻度条 + 指针 + 阈值刻线）、卡片三态 StyleBox。
- `scripts/DolDoll.gd`：按 z 序把烘好的 PNG 铺成 TextureRect（NEAREST 不过滤放大）。
- `tools/dol_map.py`：68 件衣物 → DoL 款式 / 染色 / 位置搬移的映射表（人工挑的）。
- `tools/dol_prepare.py`：取帧 / 染色 / 裁框，产出 `assets/dol/{base,clothes,icons}/` 与 `data/doll.json`。
- `Wardrobe.gd`：左＝DoL 分层小人 + 三条量表；右＝槽位分区 + 3 列卡片墙
  （缩略图 + 名称 + `E./C./A.` 三行七点 + 右上角斜标签「需 N」）。
- `PhoneDesk.gd`：相册的照片也改成 DoL 小人渲染；`ScenarioData.PHOTO_FOCUS` 的取景框
  换到新的 41×92 坐标系。

## 三、踩到的坑（值得记住）

1. **DoL 的精灵图排布不统一**：衣物多为 256×128（横向 2 帧），
   但 `img/bodywriting/*` 是 512×256（4×2 共 8 帧）**且第 0 帧是空的**。
   直接裁 `(0,0,128,128)` 会拿到全透明图。改成「扫描整个网格、取第一个非空帧」。
2. **`Button.icon_max_width` 只缩不放**：30×30 图标塞进按钮还是 30×30。
   图标落盘时按 NEAREST 放大成 60×60（= DoL 卡片里那枚的实际显示尺寸）。
3. **DoL 的刺青（`img/bodywriting`）单帧只有 2~5 像素**（DoL 自己靠 Renderer 放大），
   取不到可用图案；耳饰 / 穿环 DoL 根本没有槽位。
   → 按用户口径「挑最接近的」改成**头部小件 + 位置搬移**
   （`align: ("bbox_center", x, y)`，坐标是 41×92 取景框里的像素位）。
4. **量程不能跟着阈值走**：`Scale` 的量程若取「阈值 × 1.35」，阈值刻线就恒等于条长 74%，
   三条量表的刻线全落在同一处，等于没画。改成绝对量程（暴露 55 / 反差 100 / 未改 18）。
5. 写截图 / 测试脚本时的老坑再犯一次：`_start_new_run()` 会弹开场浮窗，
   **截 wardrobe 之前必须 `main._close_intro()`**，否则拍到的是覆盖层。
