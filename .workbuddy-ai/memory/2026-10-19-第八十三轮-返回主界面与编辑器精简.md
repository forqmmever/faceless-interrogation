# 第八十三轮（2026-10-19）：返回主界面 · 编辑器精简 · 强制穿着的「为什么」

用户四句：
1. 「加一个返回主界面的功能」
2. 「编辑器删除 开场介绍（总说明）」
3. 「编辑器流程（各套背景共用）的四个页面 删去」
4. 「为什么现在流程里没有缺陷设置 背景里也没有第三套有缺陷要求，第一套同样为什么有强制穿着的要求」

## 一、返回主界面

- `Wardrobe.gd` / `Interrogation.gd` 各加 `signal title_requested` + `home_btn`。
- 准备室：标题行最右；盘问：顶栏最右（`_ut("interrogation.home_btn")`）。
- `Main._return_to_title()`：准备室可见就 `RunSave.save_progress(wardrobe.model.equipped)`，
  再 `_show_title()`。**不算失败**（不记失败数、不清存档）。
- 盘问退出前 `_cancel_qte()` + 关递话条 + `_auto_retract_phone()`，否则下次进来会看见残留提示条。
- 文案进 `DEFAULT_UI`（`wardrobe.home_btn/home_tip`、`interrogation.home_btn/home_tip`）
  + 编辑器「界面文案」两段字段表（72 → **76 条**，冒烟计数跟着改）。

★ 探针实测：准备室点返回 → 标题可见 + 继续按钮可用；盘问点返回同理。

## 二、删「开场介绍（总说明）」

- `bgSections` 的 `meta` 节里删掉 `{k:"intro"}`。
- `bg.intro` 数据保留：`levels[i].intro` 留空时游戏仍会回落到它。
- 冒烟两条断言改成「界面不再有这一栏」+「每轮说明仍可改（⑦ 的 levels[].intro）」。

## 三、删「流程（各套背景共用）」四页

删的内容：
1. 导航 4 个 navitem（`levels` / `forced` / `qte` / `defects`）
2. `renderMain` 里 4 个渲染分支（134 行）
3. 搜索索引里那 4 段（`lv_list` / `fr_list` / `qte_list` / `df_list`）
4. 全局四段校验（201 行）
5. 加常量 `NAV_KINDS`（导航真正提供的页面），导出给冒烟做「不许加回来」的断言

★ **删全局校验时踩了一个自己挖的坑**：`knownTags` 原来定义在被删的那段里，
而**背景级**缺陷校验一直在用它 → `ReferenceError: knownTags is not defined`（冒烟当场挂）。
已在背景级那边重新 `const knownTags = new Set(catTags())`。

★ 全局页的校验规则**搬进背景级**，一条没少：
- 反差要求倒退（「比上一轮…还低 —— 曲线反了」）
- 反差要求超宽松上界（「这一轮一定无解」）
- 「必须穿」同槽位两件 → 错误；「任选一件」同槽位两件 → 提醒
- QTE 延迟 > 20 秒 → 提醒

★ 冒烟第 13 节整节重写：数据源从 `story.levels/forced_rules/qte_plan/defects`
换成 `bg.*`（拿 `enabledBgs()[0]` 当靶子），覆盖不减。

## 四、「缺陷设置去哪了」

真相：缺陷默认值一直是全局 `story.defects`（2 项：hand_tattoo / neck_brand），
每套背景的 `defects` 是**覆写**，**空数组 = 用全局那 2 项**。
背景页看着是空的 → 用户以为「这套没有缺陷」，其实游戏里有。

处理：给 `ov_defects` 加 `hint`，动态写出全局默认是什么 + 怎么改成自己的一份。
`ov_forced` / `ov_qte` 也同样补了「空着是什么」的说明。

## 五、「第一套为什么有强制穿着」

根因链：
1. 顶层全局 `forced_rules` = `[{none, rules:[hair_short]}, {none, rules:[hair_short]}]`（矛盾残留）
2. `border_post.forced_rules = []` → 回落顶层
3. 第 80 轮加的「有规则就自动升级成 fixed」→ 脏数据真的生效
4. 一局 2 轮 → 整局都在强制「利落短发」

三处一起改：
- **撤掉自动升级**（`OutfitData._ensure_forced_rules()`）
- 编辑器：「非 fixed 却写了规则」→ **错误**（不是提醒）
- **清掉顶层残留**（逐行替换 22 行 → 4 行，写完断言背景数仍是 3）

★ 副作用（好的）：`border_post` 不再被塞强制件 → 可解性死局轮次消失 →
`WardrobeTest` 耗时 **80 秒 → 35 秒**。

- 冒烟里 `const lvSec` 撞名 —— 同一函数作用域里已有同名常量，换名 `lvSecIntro`。
- 断言文案要跟着一起改：搬到背景级时把「比上一关」写成「比上一轮」、
  「mode 必须是」写成「mode 只能是」，两条断言当场变红（本轮就踩了）。
- 改 `story.json` 依旧**逐行文本替换**，不整体 `json.dumps`。
