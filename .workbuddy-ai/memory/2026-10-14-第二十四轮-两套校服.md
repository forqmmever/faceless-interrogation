# 第二十四轮：从 AU 补两套校服（2026-10-14）

## 用户口径

> 「从 au 导入一套裙长最短的校服 和一套颜色不一样的普通的校服」

追问后确认两点：

1. **「一套」= 上衣 + 裙子 + 鞋 + 袜**（每套 4 件，两套共 8 件）；
2. **裙长最短的那条要算「能把里面的内裤露出来」**（和超短皮裙、开衩短裙一样参与内裤的反差 / 暴露计算）。

## 选款依据（「裙长最短」是量出来的）

把 AU 图包 `clothes/lower` 里 8 款校服裙都取**全身像那一列**（x0..130）算裙摆底边 y：

| 款式 | 裙摆底边 y | 备注 |
|---|---|---|
| `classicschoolskirt` | **111** | ★ 最高 = 最短，选它 |
| `schoolskirtshort2` | 114 | |
| `schoolskirtshort` | 116 | |
| `schoolskirt2` | 122 | |
| `schoolskirt` / `schoolskirtplaid` | 124 | 普通及膝（`bottom_knee` 用的就是 plaid 那条） |
| `schoolskirtlong` / `long2` | 171 | 长裙 |

→ 选 `classicschoolskirt` 做「裙长最短的那套」。

- 配色：A 藏青 / B 墨绿，两套互不相同，也都不等于既有的褐色格子校裙 `bottom_knee`。

- 源图在两个图包里都有同名款（DoL 是 256×128 老几何、AU 是 512×256 新几何，`normalize_geom` 自己处理），
  所以映射统一、**不用写按包覆盖**。

## cutout 标注是怎么验的

把 `panties_lace` 的不透明像素集合减去裙子的不透明像素集合，量「露出来的内裤像素」：

| 裙子 | 露出内裤像素 | 占比 |
|---|---|---|
| `bottom_school_navy`（新，超短校服裙） | 22 px | 14% |
| `bottom_cut`（既有 cutout） | 18 px | 11% |
| `bottom_mini`（既有 cutout） | 30 px | 19% |

→ 和既有的两件 cutout 裙**同一个量级**，于是照同一口径标 `cutout`。
（`panties_plain` 在三条裙下都只露 0~1%，与既有设计一致 —— 露出来的是 gstring 两侧的系带。）

## 踩过的坑

- **新 png 没有 `.import` 元数据** → WardrobeTest 的「全部物品均有卡片图标」与「每件物品都有卡片图标」
  两条直接失败。跑一次 `godot --headless --path <proj> --import` 补齐（图标从 74 个 `.import` 变 82 个）即可。
- **「最短」不能靠文件名猜**：名字带 `short` 的是 `schoolskirtshort`(116) / `short2`(114)，
  实际最短的是 `classicschoolskirt`(111) —— 必须量裙摆底边。
- **对照图上看不出内裤**：3 倍缩略图里 gstring 露出的两侧系带只有 20 来个像素，肉眼几乎看不见；
  得放大到 6 倍、或直接量像素集合差才能确认 cutout 成立。
