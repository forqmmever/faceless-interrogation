## 一、QTE 确实失灵了 —— 根因与修复

**症状**：QTE 面板弹出来之后，按住空格进度条纹丝不动、计时器不倒数、
QTE 永远不结束（只能靠答题收掉），手感上就是「按了没反应」。

**根因**：`Interrogation._process()` 里

```gdscript
var qte_delta := 0.0        # ← 声明成 0，然后就再也没被赋过值
...
_process_expression_qte(qte_delta)   # 每帧都拿 0 推进度
```

这一行是第十三轮为了「面板刚弹出那一帧不把超时算进窗口」而写的，
本意是「只有弹出那一帧传 0」，结果写成了**永远传 0**。

**为什么测试没抓到**：所有 QTE 用例都是直接调 `_process_expression_qte(delta)`，
没人走 `_process()` 这条真实路径 —— 「_process 往里传多少」这件事根本没被测到。

**修复**：只有「本帧刚弹出」那一次传 0，之后一律传真实 delta：

```gdscript
var was_active := is_qte_active
if not is_qte_active and qte_needed and not qte_done and not interference_active:
    if delta >= qte_delay_left:
        qte_delay_left = 0.0
        _begin_qte()
    else:
        qte_delay_left -= delta
var qte_step: float = 0.0 if not was_active else delta
if is_qte_active:
    _process_expression_qte(qte_step)
```

**新增回归测试 `_test_qte_live_loop()`**（TestRunner）：全程用 `_process(delta)` 逐帧驱动，
断言按住 30 帧后进度**精确**等于 `50 + BOOST × 0.5`、计时器按真实时间倒数、
松手按 DECAY 回落、窗口走完自动结算（成功不加怀疑度 / 失败扣 EXPR_QTE_FAIL）。
断言具体数值而不是「变大了」，这样「delta 传小一半」之类的错也能抓到。

## 二、QTE 挪到屏幕最下方

- `_make_bar_overlay(fill, from_bottom)` 重写：表情 QTE 距底边 **16**（最底一条），
  同行者递话距底边 **140**（压在它上面一层）。两条分两层，同时出现也不互相盖住。
- **踩坑**：一开始拿 `MarginContainer.margin_bottom` 当「外边距」用 —— 那是内容的
  **内边距**，容器自身照样贴到屏幕底边，结果两条提示条都贴死在底边叠在一起
  （实测 QTE 顶边 615 / 递话底边 618，重叠 3px）。
  正确做法是「贴底对齐的 VBox（`alignment = ALIGNMENT_END`）+ 底部一个占位块」：
  占位块多高，面板就抬多高。
- 进度条上加了**通过线**（`qte_pass_mark`，一道浅黄竖线，位置 = `EXPR_QTE_PASS`）：
  原来只有一条光秃秃的进度，玩家看不出「按到哪儿才算过」，
  体感上也像「按了没反应」。顺手在 `_make_bar_overlay` 里给 bar 套了个 `bar_host`
  并把通过线锚在 60% 处。

## 三、排查过程中踩到的另外两个坑

1. **拍图瞬间被「挂起的切题」收掉面板**：
   截图脚本每次答题都会排一个「1.8 秒后进下一题」（`_next_question_delay` 里的
   `create_timer`），那个计时器在拍 19 号图的时刻到期 → `_load_question` → `_cancel_qte()`
   → 面板已收起。日志显示 `container=false value=16`，而我先前的判断是「进度条没渲染」，
   白查了一轮。修法：拍图前 `await _wait(160)` 把挂起的切题等完，
   再用 `_start_expression_qte()` 手动构造面板状态（不等延迟、直接设 progress=86）。
2. **隐藏的 Control 不参与布局**（第三次踩同一个坑）：
   量 `get_global_rect()` 之前必须先 `show()` 面板 + 等两帧，
   否则量出来是 0。测试里为此专门 `interro.qte_container.show()`。
