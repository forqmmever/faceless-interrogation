Godot 4.3 单机文字 AVG + 换装。一局两轮：一次换装，一次盘问。

## 故事前提

审讯官是**认识「A」的旧识**。你是 A —— 一个帮派的联络人，现在必须装成他从未见过的「B」。

- 他手上攒着一批关于 A 的**档案碎片**。你通过内线拿到了副本。
- 你要靠这些碎片拼出**他眼里的你** —— 他记得你哪些秘密、记得你长什么样 —— 再照着相反的方向打扮。
- 身为 B，**不能说只有 A 才知道的事**，也**不能前后矛盾**。他记性很好，随身带着册子。
- 身边有一个**同行者 C**：他知道你是 A，也知道你在装 B，但他既不出手相助，也不当面揭穿。

| 记号 | 是谁 | 说明 |
|---|---|---|
| **A** | 真身 | 你本人。审讯官认识的就是这个人 |
| **B** | 马甲 | 你现在扮的那个人。打扮必须和 A 的原貌尽量相反 |
| **C** | 同行人 | 知道真相，但不站你这边 |
| **审讯官** | 被欺骗的人 | 认识 A，但没见过 B。性情每局随机 |

文案里审讯官叫 **男主**、同行人 C 叫 **男二**（「球球的新玩具」那套的 C 是条狗，写作「男二（狗）」）。
这两串字存在 `data/story.json`，随时可改；代码里的 A / B / C 记号不跟着变。

### 四套背景

| 背景 | A 真身 | 审讯官 | 你装成（B） | 同行人 C |
|---|---|---|---|---|
| 边境哨卡 | 北环帮的联络人（沈棠） | 哨所的老兵 | 北境香料行商 | 车夫·老崔 |
| 城镇驿站 | 刺客公会的信使（苏绾） | 驿丞 | 流浪琴师 | 琴师·阿武 |
| 公爵府邸 | 宫廷密探（陆青梧） | 府中的执事 | 府里新招的抄写文书 | 文书·程九 |
| 港口海关 | 走私船的领航员（阿沅） | 海关的验货官 | 西码头的渔获贩子 | 水手·阿鲛 |

出厂启用的是 **边境哨卡** 与 **城镇驿站** 两套，另外两套标了草稿（`enabled: false`），
抽不到、也不列在选关面板上。

## 一局怎么打

```
开始界面 → 选关面板（挑背景）→ 准备室（换装 + 查手机）
                                ↓
                        盘问（6 道题）
                                ↓
              ┌─────────────────┴─────────────────┐
        通过（怀疑度 < 100）                 失败（识破 / 被捕 / 矛盾）
              ↓                                   ↓
        第二轮（接受度提升）                 重来本轮（回到准备室）
              ↓
        通关 → 回主界面
```

- 一局 = **随机一套背景 + 随机一具原貌 + 随机一种审讯官脾性**，共 **2 轮**。
- 每轮 = 一次换装（准备室）+ 一次盘问。
- 失败只作废**这一轮**：原貌、已读的短信、擦清的照片、接受度都留着，只有这一轮的打扮要重来。
- 每轮赚到的接受度会立刻存进账号（`user://profile.json`），**全局保留**，重来也不退。

## 阶段一 · 准备室

界面只剩两件事：**换装** 和 **手机**。左边是纸娃娃预览与两条量表，右边是 12 个可见槽位，
每个槽位一段分区、下面铺开这个部位的衣物卡片。手机是左下角按钮弹出的浮层。

```
┌──────────────┬──────────────────────────────────────────────────────┐
│ 换装预览 原貌 │  ▍发型                        当前：利落短发          │
│  ┌────────┐  │  ┌───────────────┐ ┌───────────────┐ ┌─────────────┐ │
│  │ 纸娃娃 │  │  │[图] 利落短发  │ │[图] 侧编辫    │ │[图] 垂肩长发│ │
│  └────────┘  │  │ E ●○○○○○○     │ │ E ●○○○○○○     │ │      …      │ │
│  当前伪装 …  │  └───────────────┘ └───────────────┘ └─────────────┘ │
│ ───────────  │  ▍头饰                        当前：宽檐旅行帽        │
│ 暴露值 ●○○…  │  …（12 个槽位一路往下滚）                            │
│ ▓▓▓▓▓▼░░│░░  │                                                      │
│ 4 / 30       │                                                      │
│ 反差值 ●○○…  │                                                      │
│ ▓▓▓▼░░░░│░░  │                                                      │
│ 0 / 125      │                                                      │
├──────────────┴──────────────────────────────────────────────────────┤
│                                    [手机]  [一键达标] [进入盘问环节 >] │
└─────────────────────────────────────────────────────────────────────┘
```

**这一阶段不替你下结论。** 界面上只把数字摊开，不写「通过 / 不通过」。
真正的审判在阶段二开门那一瞬间。

### 三个数值

| 数值 | 含义 | 规则 |
|---|---|---|
| **暴露值** | 这件衣服有多暴露 | 全部已装备衣物的暴露值**总和不可超过上限**；上限 = `10 + 接受度 × 2` |
| **接受度** | 你的「接受程度」 | 决定能否装备高门槛衣物（硬门槛），每轮提升 |
| **反差值** | 与「他记得的样子」的偏离程度 | 全槽位求和，**需 ≥ 本轮要求**，否则开门即被识破 |

两轮的出厂数值：

| 轮 | 接受度 | 暴露上限 | 反差要求 |
|---|---|---|---|
| 第一轮 | 10 | **30** | **125** |
| 第二轮 | 19 | **48** | **150** |

### 反差怎么算

```
单槽位反差 = |你穿的暴露度 − 原貌那件的暴露度| × 5
           + （暴露度相同、但不是原貌那件）? 「换了件」分 : 0
```

- **系数 5** 在 `rules.contrast_per_exposure`，可改。
- 「换了件」分：基础 **2**、发型 **12**、妆容 **10**（`rules.contrast_same_exposure_bonus` 等）。
  两个条件缺一不可：暴露值相同**且**不是原貌那件。
- **穿回原貌那件 = 0 分**，无论暴露度多少。
- 所有**看得见**的槽位都参与（过内衣曝光门控的那些才算）。

量表的量程是**绝对**的：暴露值 71、反差值 270。所以两轮的刻线落在不同位置，
一眼能看出预算在放宽。

### 两个缺陷

角色带两个无法消除的生理缺陷：

| 缺陷 | 可用的遮挡标签 |
|---|---|
| **右手背黑帮血蛇刺青** | `长袖`（2 款上衣） |
| **颈侧奴隶烙印** | `高领` 或 `围巾` |

而 A 的原貌恰好是**一件高领长袖衬衫同时遮住两处**。想把反差堆高就必须脱下它，
遮挡责任被迫转移到颈饰槽 —— **藏缺陷**与**不像自己**天然对立。

**某个缺陷的全部遮挡物若集中在同一个槽位，那个槽位就不会被强制装备占用**
（`OutfitData.forced_locked_out_slots()`），否则「强制穿短袖」= 刺青必露 + 上衣换不掉 = 死局。

### 内衣曝光门控

`bra` 与 `panties` 两个槽位的数值**只有在这件内衣看得见时才计入**。三条路任一成立就算：

| 路径 | 判据 | 标在哪 |
|---|---|---|
| ① 透明外衣 | 半透 / 薄纱 / 蕾丝，透过去就能看见 | 那件外衣上写 `"see": "sheer"` |
| ② 镂空开档 | 开衩 / 超短 / 露腰，从开口处直接看见 | 那件外衣上写 `"see": "cutout"` |
| ③ 直接外穿 | 同侧外衣这一层空着，内衣就是最外层 | 那件「不穿」上写 `"bare": true` |

判据是「**上面没有任何一层把它挡住**」，不是「有没有外衣」—— 因为上半身有两层：

| 搭配 | 结果 |
|---|---|
| 高领长袖衬衫 + 蕾丝内衣 | 藏住了 |
| 蕾丝半透上衣 + 蕾丝内衣 | **算**（透出来） |
| （不穿上衣）+ 蕾丝内衣 | **算**（直接外穿） |
| 高领衬衫 + 半透罩袍 | 藏住了（**衬衫**挡着） |
| 吊带连衣裙 + 蕾丝内衣 | 藏住了（连衣裙上半截挡着） |

判定时先跳过下架的槽位，再看剩下那几层。这条门控**同时管暴露值与反差值** ——
看不见就既没风险、也没意义。界面上藏起来时那两张卡片会压暗，悬停提示「外衣盖得严实」。

一键达标的求解器把「上衣 + 内衣」「下装 + 内裤」**并成一组一起选** ——
内衣的贡献取决于外衣，分开选会算出对不上的「最优解」。

### 一键达标

右下角一颗调试按钮，一次点掉本轮**全部**服装要求：强制装备穿上、暴露不超上限、反差达标。
它**不**替你决定穿什么好看，只保证判定能过。

## 阶段二 · 高压盘问

审讯官 = 认识 A 的旧识，全程在试探。

### 开门即识破

门一开，他抬眼 —— 看见的不是 B，是 A。

如果换装判定没过（反差不够 / 缺陷没遮 / 超暴露上限 / 强制装备没穿），
他放下册子，念出那个你早就不打算再听见的名字：

```
哨所的老兵抬起头，视线在你脸上停住了。
他看了很久，久到旁边的人都安静下来。然后他放下手里的册子，念出了那个你早就不打算再听见的名字 ——

「怎么是你，沈棠。」

· 反差值 7 < 要求 125
```

本轮到此为止，结果按钮写着「重来本轮」。

### 六道题

每轮 **6 道**（`rules.questions_per_level`，可改；某一轮想单独定可以在 `levels[].questions_per_level` 覆盖）。

出场顺序**就是题库里的顺序** —— 在编辑器「题库」页拖一拖就能调。出厂那一份：

| 位置 | 是什么 | 从哪来 |
|---|---|---|
| 1 | 本轮**新增**的说法题（问一件新事） | 固定给这一轮 |
| 2 | **同行者提问**（打的就是第 1 道刚立下的说法） | 固定给这一轮 |
| 3 | **盲区题**（档案里没有、短信里也没提） | 固定给这一轮 |
| 4 | **跨轮复问**（翻出前面某一轮立过的说法再问一次） | 通用池里标了 `recall` 的那道 |
| 5~6 | 档案题 | 通用池随机抽 2 道 |

第 1 轮没有「上一轮」，所以不排复问，那一道让给档案题（第 1 轮 3 道档案题）。

**一轮之内不会出现前后矛盾** —— 同一轮里每件事最多只问一次，矛盾只来自跨轮复问。

### 题目的数据形状

每套背景只有一份 `questions[]`，**每道题是一个自带全部属性的对象**。
判定不看「这道题属于哪一类」，**只看每个选项自己的 `tone`**。

| 字段 | 说明 |
|---|---|
| `id` | 题目 id（一套背景里唯一） |
| `level` | `-1` = 通用池，`0..N` = 固定给第 N+1 轮 |
| `speaker` | 谁在问。存量数据里写了照旧生效，没写就是审讯官问 |
| `text` | 题面 |
| `setup` | 可选：前置说明（盲区题用它交代「档案里没有这件事」） |
| `card` | 可选：来源档案卡。**挂了卡就按卡的归属判** |
| `fact` | 可选：挂到哪条事实上，参与「跨轮不许改口」的一致性检查 |
| `recall` | 可选：标了它就是跨轮复问用的那道 |
| `qte` | `{kind, delay}`：这道题出哪种 QTE、几秒后出现 |
| `options[]` | 候选回答 |

`options[]` 每一项：

| 字段 | 说明 |
|---|---|
| `text` | 选项文本（`tone: silence` 时可以留空，用出厂那句通用文案） |
| `echo` | 可选：选完之后接在下一题题面前的那段。留空 = 显示 `text`；填了 = 原样显示。按钮上的字不变 |
| `tone` | **语义标签**，判定只看它（七种，见下） |
| `suspicion` | 选了它怀疑值加多少。**留空 = 用全局默认**（这样性情机制才生效） |
| `value` | 只有 `version` 要填 —— 代表哪个版本，跨轮比对靠它 |
| `ending` | 可选：填 `leak` = 当场暴露收场。和 `tone` 分开 |
| `shake` | 可选：选了它震一下屏（填力度） |

七种 `tone`：

| tone | 含义 | 代价 |
|---|---|---|
| `correct` | 照实答（B 卡的档案，对得上就没事） | `rules.correct_delta`（**0**） |
| `leak` | 说漏嘴（只有 A 才知道的事） | `rules.leak_delta`（**100**，当场出局） |
| `version` | 事实题的某个版本 | 由一致性判定 |
| `bluff` | 撒谎 | 按审问官性情现算 |
| `evade` | 回避 | 按审问官性情现算 |
| `silence` | 沉默 | `rules.silence_delta`（**12**，与性情无关） |
| `made_up` | 硬编一个细节（盲区题） | `rules.blind_made_up_delta`（**48**） |

**自行编辑的背景**（`questions_source = "manual"`）不自动加说话人名牌，也不加「你：」前缀 ——
题面与回应都按原文显示。自动生成的背景保留名牌。

### 四种题

**档案题** —— 考「这是不是 B 该知道的事」。判定按卡的归属（`card.owner`）：

| 卡的归属 | 「正面回应」变成 | 效果 |
|---|---|---|
| **B 卡**（你编造的伪装档案） | 照着档案答出细节 | 怀疑度 **0** |
| **A 卡**（只有真身才知道） | 脱口而出 A 的真相 | 怀疑度 **拉满 → 当场暴露** |

固定 4 个选项：A. 正面回应 / B. 临时胡编 / C. 回避 / D. 沉默。

**说法题** —— 给你三个版本，选哪个都可以，**没有标准答案**，但选下去就是你的口径，
之后不许改口。跟短信里的官方口径一致则不加不减，不一致 **+70**。

**盲区题** —— 他问一件档案里没有、短信里也没提的事。**没有内容上的正确答案**。
2~3 个选项（硬答 / 撒谎 / 回避），**正解是「撒谎」与「回避」里代价更低的那一个** ——
而哪个更低完全由审讯官的性情决定。所以这题的答案不在档案里，在你有没有按他的脾性去想。

**同行者提问** —— 他插一道正式的题，抛一个**错的版本**来试你：

| 你的回应 | 后果 |
|---|---|
| 顶回去（说的还是那套说法） | 不加不减 |
| 顺着他说 | 按该选项的代价 |
| 不正面接 | 不加不减，不算表态 |

★ **他这一问在轮内不算前后矛盾** —— 他只让你掉血，不当场定罪。无论你怎么答，
这句话都进了册子；他给的错版本**不会**写进你的口径。

### 审讯官的性情

每局随机一种，决定「撒谎」和「回避」各要付多大代价：

| 性情 | 描述 | 撒谎 | 回避 |
|---|---|---|---|
| **多疑** | 你说得越顺他越要反着再问一遍 | **+45** | +12 |
| **迟钝** | 记性一般，抓不住话里的破绽 | **+6** | +10 |
| **精明** | 不用吓唬你，他只要让你自己说错 | +30 | +8 |
| **急躁** | 讨厌绕圈子，你一回避他就磕笔 | +10 | **+32** |
| **心软** | 办差多年也累，不太想为难人 | +18 | **+6** |

**这些信息由「翻开备忘录」这个动作登记**。翻开过一次，就算「记下了他的脾性」，
之后盘问里**危险的那一项选项会被标红并加上 ⚠**。没翻过就什么提示都没有。

### 表情 QTE

屏幕最下方出现一条蓝色提示条，**4 秒窗口**，**只按空格**把进度顶过 **80%** 通过线。

```
触发概率 = (暴露值 − 10) / (60 − 10)     夹在 0 ~ 1
```

| 暴露值 | 触发概率 |
|---|---|
| ≤ 10 | 0 —— 一次都不出 |
| 30 | 0.40 |
| ≥ 60 | 1 —— 每题必出 |

按当前接受度推算，两轮穿到满暴露时大约是 **40% / 76%**。

四条规则：

| 规则 | 说明 |
|---|---|
| **延迟起手** | 切到新题之后先等 **3 秒**才出现，让你看清题目 |
| **单阶段** | 一题只做一次，本题答完这条 QTE 就结束 |
| **锁手机也锁选项** | QTE 期间手机用不了，选项也锁着；顶过 80% 才解锁 |
| **不移位** | 提示条是 anchor 固定的覆盖层，不进布局，不会挤动别的按钮 |

| 结果 | 后果 |
|---|---|
| 压住了 | 不加不减，屏幕轻抖（幅度 3） |
| 没压住 | 怀疑度 **+48**，屏幕抖一下（幅度 10） |

**第 1 题固定不出 QTE**（开场先让你把第一句话说完）。
题目显式写了 `qte: expression` 的照出；没写 `qte` 的题 = `none`，**连随机递话也一起压掉**。

### 同行者干扰

他还会凑到审讯官耳边递半句话，把目光往对的地方引。**间隔固定 14 秒**，与暴露值无关。

| 种类 | 出现时机 | 怎么抵抗 | 窗口 |
|---|---|---|---|
| 单键干扰 | 多数时候 | 按一下 **空格** | 2.6 秒 |
| 组合干扰 | 每 **3 次**里出 1 次 | 依次敲 **J → K → L**（敲错当场判负） | 2.6 秒 |

- 打断成功 → 怀疑度 **−3**
- 打断失败 / 超时 / 组合敲错 → 怀疑度 **+36**

**提问与干扰是两条独立的路子**：提问是正式题目（进题目序列、走口径判定），
干扰是纯 QTE（不进序列，只打断）。同一轮里他会同时用这两招。

### 掏出手机

盘问界面左下角有「掏出手机」按钮，位置固定不动。点开 → 手机浮层盖在盘问界面上，
**左边题目和选项照样能点**（覆盖层不吃鼠标事件）。选完答案自动收回，换下一题也自动收回。

代价是有的 —— 他看得见：

| 掏出次数 | 后果 |
|---|---|
| 第 1 次 | 他当你是在整理行头，不追究 |
| **第 2 次起** | 怀疑度 **+16 × 越界次数**（第 2 次 +16、第 3 次 +32、第 4 次 +48…） |

压表情的时候手机是锁着的：蓝色 QTE 条一出来，手里那部先自动收回、按钮变灰并改成
「压表情时收起来」，压完立刻解锁。

### 怀疑度与胜负

| 规则 | 说明 |
|---|---|
| **轮内只涨不跌** | 一切负增量归零。答对口径、复问一致、打断同行者的话 —— 这些只写文案不加不减 |
| **轮间按比例衰减** | 本轮结束时写进 `suspicion_carry`；进下一轮时 **× 0.5**，下限兜在 **10** |
| **起点** | 第 1 轮 **20** |

**结算条件：**

| 条件 | 结果 |
|---|---|
| 换装判定没过 | 开门即识破，本轮结束 |
| 怀疑度达到 **100** | 当场被捕 |
| 累计 **2 次**前后矛盾 | 当场识破 |
| 6 题答完且怀疑度 **< 100** | 本轮通过，进入下一轮 |
| 2 轮全部通过 | 整局通关，回主界面 |

任何一轮失败 → **回到本轮开始**（本轮的准备室重来），不退回上一轮。

## 手机

准备室与盘问共用同一部手机。四个 App：

| App | 内容 | 机制 |
|---|---|---|
| **消息** | 三段：审讯官本人 / 同行的人 C / 朋友 | **读过才作数**，逐轮解锁（第 i 轮新来 1 条） |
| **相册** | 别人偷拍的 A | 糊、有反光、有噪点。反复「擦掉反光」提升清晰度，擦到 70% 才认得出。有些照片是废片，再怎么擦也看不清 |
| **备忘录** | 这一局的手记，**作者逐轮自己写** | 每轮一份完整清单，不累积。正文支持 `{真身}` `{审问者}` `{性情}` `{同行者}` 等占位符 |
| **备注** | 按轮次累积的问答记录 | 第一轮整页空着；从第二轮起，前面每一轮的问答都摊在这儿 |

**三段短信各管一件事**：

| 顺序 | 发信人 | 里面是什么 | 读了会怎样 |
|---|---|---|---|
| 1 | 审讯官本人 | 事件短信。正常流程里**空的**，整组不显示 | 读到就知道「他看见了」，不揭示任何口径 |
| 2 | 同行的人 C | 他知道你是 A，**不给你口径**，只提醒你他一直在旁边 | **读完学到 0 条** —— 这是设计，不是漏做 |
| 3 | 朋友 | **官方口径的唯一来源** | 每条揭示 1 个「B 的官方说法」。没读过的盘问时只能靠蒙 |

★ 为什么 C 的短信故意不带口径：整作的核心是「A 是孤身一人在演 B」。
如果 C 也给你口径，就多了一个正确答案来源。这条约束有断言守着。

**备忘录**：每轮可以写好几段，进游戏拼成一段连续文字。每一轮还能勾一个
「末尾自动接一行该怎么答」—— 那行取自本轮审讯官的性情对策。
备忘录可以一个字都没有，**盲区题的反馈不依赖它**（反馈直接读性情表）。

**相册**：照片是把本局原貌图层塞进 `SubViewport` 现拍的，所以永远和本局原貌一致。
反光效果由一个 canvas_item 着色器实时算（模糊 + 径向晕光 + 斜向反光条 + 冲淡 + 颗粒）。

| 键 | 内容 | 合并语义 |

## 文本编辑器

`open_story_editor.bat` 会起一个本地小服务（8765），编辑器**直接读写** `data/story.json`。
用 `file://` 打开只能读内置快照，改不了文件。

左侧导航：

| 组 | 能改什么 |
|---|---|
| **基础** | 数值规则（题数 / 怀疑度 / 反差 / QTE / 干扰…）、界面文案、结局文案 |
| **背景** | 每套背景的卡 / 事实 / 题库 / 短信 / 轮次 / 强制穿着 / QTE 计划 / 缺陷 |
| **题库** | 每道题的题面、选项、`tone`、代价、QTE，拖动能调顺序 |
| **手机** | 外壳、消息页文案、备忘录格式、相册文案、备注文案 |
| **服装** | 物品数值、原貌池 |
| **校验** | 全量检查，**只放问题不放说明** |

**「自行编辑」模式**（`questions_source = "manual"`）：用不到的字段整节收起来（数据不动）。
判定改为只看怀疑值，不建档案卡与事实，不判盲区题。

**校验面板只放「问题」**：出厂数据必须 **0 错误 0 提醒**。
带占位符的字段空着会标红（`"" % 参数` 会直接报错）；不带占位符的字段空着**不算问题**，
会回落到出厂文案。

改完 `story.json` 要重建编辑器的内置快照（`build_story_editor.py`），冒烟测试读的是那份。

## 美术资产

小人**不是自己画的**，是现成的分层图包逐件映射过来的。只用 **AUfemale** 这一套
（社区重画，人物更高、有完整双腿）。

### 分层画布

所有图层裁到**同一个取景框 68×203**，换装时小人才不会跳。
染色烘在构建期、不放在运行时（染色是逐像素乘法，颜色又是固定的）。

### 管线

```
tools/dol_map.py（映射表）
      ↓
tools/dol_prepare.py（取帧 / 染色 / 裁框）
      ↓
assets/dol_au/*.png  +  data/doll_au.json
      ↓
godot --headless --path . --import      ← 漏了这步 Godot 看不见新图
```

### 挑贴图的规则

图包里的文件名不总是 `full.png`，按这个顺序挑（挑到全透明的就跳过）：

1. 先滤掉 `-acc` / `_acc` 变体（那是「附加装饰」那层，不是主体）
2. `full.png`
3. `full*`（不少件只有 `full-alt` / `full_gray` / `full-long`）
4. 带 `idle` 的（小人永远用站立手臂）
5. 数字名（`1.png` / `2.png` …）
6. 其余按名字排第一个

### 头发

头发（侧面 / 刘海 / 脑后三块）是**纯灰度蒙版**，换色必须走 `tint()`：
结果 = 发色 × 蒙版灰度，外加 `gain` 抬亮度。

**只能点名 AU 重画的新几何款**，不能写成「候选列表」—— 图包里同时留着旧款
（同名、256×128、还是红色），候选列表会先撞上旧款。
硬条件是**几何 512×256** 且**饱和度 0.00**，两个条件缺一不可。

### 成装

`dress` 是**两层源图叠加**（`upper/<款>` + `lower/<款>`，upper 在前）。
只取一层就只有上半身。加新成装第一件事：查这两层是否都在。

## 已知限制

- **自行编辑（manual）仍受「每轮 6 道题」约束**。想「一局只问 2 道」得改数值规则，或把题按轮分配。
- **`relation` / `desc` / `speaker` 已从编辑器下线，运行时仍在读**。现在只能直接改 `story.json`。
- **手机外观预览没有**。想看效果只能跑游戏或看截图。
- **`index.html` 是早期 HTML5 原型**，规则与数值早和 Godot 版不同步，未删未清。
- **`border_post` 还留着 12 条 `cards`**（两套启用的背景都是自行编辑、`cards` 为空）。
  要不要在导出时清掉未定 —— 保留的理由是切回自动生成还能用。
