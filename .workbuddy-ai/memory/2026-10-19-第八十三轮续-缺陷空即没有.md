# 第八十三轮（续）：还回误删的全局缺陷表 · 「空 = 没有缺陷」

用户口径：「不要把脏数据留下来，情景一根本没有设置身体缺陷，我写的那两套的东西，没有提到就不要动」。

## 一、我上一轮误删了全局缺陷表（数据事故）

`git diff 3d33650 cde8491 -- data/story.json` 能看到：

```
-	"defects": [
-		{"id": "hand_tattoo", ...},
-		{"id": "neck_brand", ...}
-	],
+	"defects": [],
```

原因：我清理顶层 `forced_rules` 的脚本用「括号深度」算结束行，但 `forced_rules` 里每一项
`{...}` 自己就闭合了一次，深度提前归零 → 行区间**越过了** `qte_plan`，把 `defects` 一起吞了。
当时的断言只查了 `forced_rules` 和 `backgrounds` 数量，**没查 defects**，所以没拦住。

★ 教训：**逐行替换前，先把「区间结束行」打印出来人眼看一遍**，并在写盘后断言
「所有同级段的条数都没变」，不只断言被改的那一段。

已按第 82 轮内容逐行还原，三套背景的 `defects` 一个字没动。

## 二、「情景一根本没设缺陷，游戏里却有」—— 空被当成了「没写」

`_ensure_defects()` 原来是：

```gdscript
var ov: Array = _bg_defects if not _bg_defects.is_empty() else ScenarioData.defects_override()
var src: Array = ov if not ov.is_empty() else DEFAULT_DEFECTS
```

`"defects": []` 走完两遍 `is_empty()` 就落到 `DEFAULT_DEFECTS`（出厂 2 项）。
**编辑器里那一节是空的，游戏里却真的要求遮手背/颈侧** —— 用户看到的就是这个。

改成三级回落 + 两个「写没写」的门面：

```gdscript
func defects_declared() -> bool          # story.json 顶层写过 defects 吗
func bg_has_defects(bg_id) -> bool       # 这套背景写过吗
```

```gdscript
var declared := _bg_defects_declared
var ov: Array = _bg_defects
if not declared:
    ov = ScenarioData.defects_override()
    declared = ScenarioData.defects_declared()
var src: Array = ov if (not ov.is_empty() or declared) else DEFAULT_DEFECTS
```

| 顺序 | 条件 | 结果 |
|---|---|---|
| ① | 本套写过（哪怕 `[]`） | 用本套 —— **空就是没有** |
| ② | 没写过 | 用全局（`[]` 也算写过） |
| ③ | 都没有 | 才用 `DEFAULT_DEFECTS` |

实测：

```
border_post 0 项 / scene_1 0 项 / scene_2 0 项
全局 defects = 2（数据还在，没人用）
抹掉 border_post 的 defects 键 → 生效 2 项（回落链正常）
```

## 三、编辑器说明改口

原来：「空着 = 用全局默认的 2 项」—— **错的**。
现在：「空着 = 这一套**没有**身体缺陷（不会套用别处的默认）」。

## 四、测试改 4 条（都写死了「一定有 2 处缺陷」）

| 原断言 | 改成 |
|---|---|
| 「默认读到 2 处缺陷」+「每处都有字段」 | 「缺陷表结构完好（N 处，允许为 0）」 |
| 「手套+立领 = 两处全遮」 | 「能遮住的处数 = 缺陷总数」 |
| 「短袖+空脖子 → 两处都暴露」 | 「→ N 处全露着」 |
| 「换成短袖后手背刺青暴露 / 颈侧烙印暴露」 | 这一节**自带出厂缺陷表**跑，跑完还原 |

★ 最后那条的判据：**机制测试不能依赖「当前数据配没配」**。
现在用户数据里 0 项缺陷，遮挡逻辑照样被完整验到。
