## 二、拆完才看见的两个真相

### ★★ 1. README 一直在描述「玩家永远抽不到的东西」

`data/story.json` 的 `backgrounds` 是**整段替换**，实际装的是：

```
border_post   enabled=false   边境哨卡（出厂那套，已停用）
scene_1       enabled=true    玩玩的关系（作者写的）
scene_2       enabled=true    杜鹃之女（作者写的）
bg_new_1      enabled=false   空的
```

而出厂四套（边境哨卡 / 城镇驿站 / 公爵府邸 / 港口海关）只活在
`ScenarioData.gd` 的 `DEFAULT_BACKGROUNDS` 里 —— **游戏跑起来一套都抽不到**。

旧 README 那张「四套背景」表（A 真身 / 审讯官 / 你装成 / 同行人）描述的正是这四套。
第 97 轮重写时它没被质疑，因为它「看起来像设计文档」。

**判据**：写「有哪些 X」之前，先看**运行时真的读的是哪份**。
`story.json` 覆盖了什么，出厂常量就不再是答案。

### ★★ 2. 盘问章节写的是 auto 模式，跑的是 manual 模式

旧 README 的「六道题」写「位置 1 说法题 / 2 同行者提问 / 3 盲区题 / 4 跨轮复问 / 5~6 档案题」，
「四种题」写档案题按 `card.owner` 判 B 卡 / A 卡 —— 这套**只对 auto 背景成立**。

`scene_1` / `scene_2` 都是 `questions_source = "manual"`：没有 `cards`、没有 `facts`、
没有题序规则，`questions[]` 就是一张手写清单，判定只看选项自己的 `suspicion`。

`Interrogation.gd:1210` 那行是关键：

```gdscript
var is_blind := fid == "" and cid == "" and not is_companion \
    and not RunData.questions_are_manual()
```

第 56 轮加的那个 `and not questions_are_manual()` 就是为了不让 manual 的题**全部**变成盲区题。

**改法**：拆成两节 ——「选项怎么设计」（manual）与「另一种排法：模板那四套」（auto）。

## 四、性情在 manual 里还剩什么

`_build_unified_options()`：

```gdscript
delta = float(d.get("suspicion", td["bluff_d"]))   # 写了 suspicion 就用它
```

所以 manual 下**代价与性情无关**。但 `_trait_options()` 的 ⚠ 标记照旧：

```gdscript
var bluff_danger := known and ScenarioData.trait_is_dangerous(tr, "bluff")
```

→ 性情只管两件事：备忘录里「该怎么答」那一行，和危险选项的 ⚠ 前缀。
README 里加了这句限定，否则「性情决定撒谎 / 回避代价」在作者那两套上是假的。

⚠ 顺带记一个**已知怪相**（没改）：manual 里一个 `bluff` 选项即使 `suspicion: 0`，
只要当前性情认为 bluff 危险，也会被打上 ⚠。代价与提示可能对不上。
